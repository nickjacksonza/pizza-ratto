Pizza Rattomenu editor set-up

  1. On GitHub, create a fine-grained token for the nickjacksonza/pizza-ratto repository only, with Contents: Read and write, and Actions: Read-only.
  2. Paste it here and choose the owner's password: at least 16 characters (four or five random words work well).
  3. The page encrypts the token with the password and saves only the encrypted copy to the repo. The token itself is never stored.
